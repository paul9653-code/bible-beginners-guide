# 성경입문자와 질문자들을 위한 성경 가이드앱

성경 구절과 기독교 주제를 한국어로 설명하는 무료 Codex 플러그인입니다. 본문 확인, 이야기와 문맥, 역사·문화 배경, 핵심 의미, 오늘의 적용을 차례로 살펴봅니다.

## 설치

1. Codex CLI를 사용할 수 있는 터미널에서 다음 명령을 실행합니다.

   ```sh
   codex plugin marketplace add paul9653-code/bible-beginners-guide
   ```

2. ChatGPT 데스크톱 앱을 다시 시작합니다. Codex의 **플러그인 디렉터리**에서 **김영진의 성경 가이드**를 선택한 뒤 이 플러그인을 설치합니다.
3. 새 대화에서 플러그인을 선택하고 질문합니다. 예를 들어 “요한복음 3장 16절을 성경 입문자에게 설명해 줘”라고 물어보세요.

이 저장소는 Codex에서 추가하는 사용자 지정 마켓플레이스입니다. 설치에는 해당 기능을 지원하는 Codex 환경이 필요합니다. 플러그인 자체는 무료이며, 호스트의 이용 조건은 별도로 적용됩니다. [마켓플레이스 설치 공식 안내](https://developers.openai.com/plugins/build/plugins)
